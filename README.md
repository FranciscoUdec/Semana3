# Tarea Semana 3 

Análisis a un negocio, calculando ganancias netas a partir de ventas y costos.

## Datos

Se utilizan datos de 4 meses:
- `ventas`: Ventas mensuales en pesos.
- `costos`: Gastos mensuales en pesos.
- `mes`: Número del mes analizado.

## Cómo correrlo

Abrir y ejecutar el script:
`scripts/tarea_s3.R`
